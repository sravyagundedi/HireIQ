# 5-Minute Demo Script

## 0:00–0:30
Introduce HireIQ and the problem.

## 0:30–1:15
Show interviewer question set and rubric.

## 1:15–2:30
Start candidate interview, record an answer, submit it.

## 2:30–3:15
Show asynchronous processing and transcript.

## 3:15–4:00
Show LLM score, sentiment, keywords and confidence signal.

## 4:00–4:40
Open manager dashboard and compare candidates.

## 4:40–5:00
Download PDF and briefly explain bias review and architecture.
